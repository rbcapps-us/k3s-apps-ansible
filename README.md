# Ansible Collection - rbcapps_us.k3s_cloud_native_pg_ansible

An Ansible collection to easily install CloudNativePG high-availability PostgreSQL on a K3s cluster which has been provisioned by the [rbcapps_us.k3s_cluster_ansible](https://github.com/rbcapps-us/k3s-cluster-ansible) Ansible Galaxy collection

## Test using the examples directory

For a full walkthrough of the installing the applications which this Galaxy collection includes, see [examples/README.md](examples/README.md).
